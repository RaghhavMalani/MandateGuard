# INT-2 engineering artifacts

These files are non-benchmark engineering outputs. They do not change or
support a registered benchmark claim.

`retrieval_sweep.jsonl` and `retrieval_summary.json` were generated by the
offline retrieval-only runner over six synthetic commerce catalog queries. The
matrix contains 192 observations (6 queries x 32 configurations). The runner
used deterministic hashing embeddings and made zero semantic or live API
calls. Local latency fields are measurements, not stable golden values.

`downstream_selection.json` is an explicit example selection recorded before
any live Stage-B execution. It has status `RECORDED_NOT_EXECUTED`; no live
semantic result is represented here. The Stage-B review-rate and unsafe-
direction CSVs therefore contain headers only until selected execution occurs.

`cache_experiment.json` and its CSV compare an offline-fake cold semantic MISS
with an exact HIT. They are not live-provider measurements. Raw token counts
remain null where the fake provider exposes no usage, so estimated cost is
null. All five input mutations are cache misses and Razorpay calls are zero.

No hypothesis in `docs/INT2_RETRIEVAL_EXPERIMENTS.md` should be described as
supported until a reviewed experiment is run and interpreted.
